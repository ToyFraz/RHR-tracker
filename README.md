The app uses the information already gathered by Pebble Health, so it is very lightweight. 

It takes the heartrate measurements from the night before from 12:00 until 4:00 am. It discards any high or low ones, and then averages them for the Resting Heart rate daily value.

It displays the current Resting Heart Rate Daily Value at the top, and has a 2 week graph and 120 day graph. Middle button to see the 120 days.

If you delete the app from your watch, all the historical data will be lost.

Coded with Gemini.
